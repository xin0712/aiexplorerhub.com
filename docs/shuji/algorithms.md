# 算法与数据结构

算法是计算机科学的**核心学科**，这个领域的经典也最"硬"。

**为什么值得投入**：算法决定了你解决问题的上限。写业务代码时它不明显，但当数据量上来、性能成为瓶颈时，**有没有算法功底，差别是"能不能解决"而不是"快慢"**。

## Introduction to Algorithms (CLRS)

**Cormen、Leiserson、Rivest、Stein** · 初版 1990 · 第 4 版 2022

**领域**：数据结构与算法

经典的算法分析教材。理解**复杂度、递归、动态规划、树、图和算法设计**。

**定位**：MIT 算法课程采用的经典教材之一，**值得终身保留作为参考书**。

> 它的用法不是「读完」，而是**放在手边随时查**。第 4 版补了新的算法和内容。

### 覆盖的内容

| 部分 | 主题 |
|---|---|
| 基础 | 复杂度分析、渐进记号、递归式求解 |
| 排序与统计 | 快排、堆排、线性时间排序、中位数 |
| 数据结构 | 哈希表、二叉搜索树、红黑树、B 树 |
| 高级设计 | 动态规划、贪心、平摊分析 |
| 图算法 | 最短路、最小生成树、最大流 |
| 进阶专题 | 线性规划、NP 完全性、近似算法 |

### 怎么用它

- **不要试图从头读到尾**——书太厚，且很多章节你短期内用不上
- **配合课程或项目带着问题读**——需要哪种算法就翻哪一章
- **做习题**——算法这门学问，看懂和会做是两件事
- **没做出来的题做标记**——三个月后回头再做一遍，这是算法训练的关键

:::tip 一个实用的读法
第一遍只读**复杂度分析、排序、哈希表、二叉树、图算法**这几块——它们覆盖了日常工作 90% 的场景。

动态规划、NP 完全性这类留到需要时再啃。
:::

## The Art of Computer Programming (TAOCP)

**Donald E. Knuth** · 首卷 1968

**领域**：算法分析（深度）

计算机算法研究史上**地位极高的巨著**，覆盖基础算法、半数值算法、排序和搜索等。

**定位**：经典地位毋庸置疑，但**数学与算法深度非常高**。建议作为**长期藏书和研究参考**，不安排在第一年通读。

> Knuth 在 1962 年动笔，至今仍在写。这套书本身就是一段计算机科学史。

### 各卷内容

| 卷 | 主题 |
|---|---|
| 第 1 卷 | 基础算法（包含 MMIX 汇编语言） |
| 第 2 卷 | 半数值算法（随机数、算术） |
| 第 3 卷 | 排序与查找 |
| 第 4 卷 | 组合算法（分册出版中） |
| 第 4A 卷 | 位运算技巧与布尔函数 |

### 为什么很多人读不下去

- **用 MMIX 汇编语言**讲算法——一门为教学造的假想机器语言
- **数学推导密集**——很多章节本质是数学证明
- **习题极难**——部分题目是未解难题

:::warning 关于 TAOCP 的现实建议
它常被列为"必读"，但**真正读完的人极少**。

更实际的做法：**先读 CLRS 打基础，需要做算法分析时再回来查 TAOCP 的相关卷册。**

把它当**工具书和题库**，而不是"从第一页读到最后一页"的书。
:::

## 这个领域怎么排

| 顺序 | 书 | 策略 |
|---|---|---|
| 1 | CLRS | 精选章节，配合实践 |
| 2 | TAOCP | 长期参考，不通读 |

**两本都不是入门读物**——建议在写过一定量代码之后再回来。

## 什么时候该回来读

不必一开始就啃这两本。**出现下面这些情况时，是读它们的好时机**：

- 代码跑得慢，不知道该从哪优化
- 面试准备（CLRS 覆盖了绝大多数算法面试题的理论基础）
- 想理解某个库内部的实现（比如数据库索引为什么用 B+ 树）
- 遇到需要自己设计数据结构的问题
