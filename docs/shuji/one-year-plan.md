# 一年精读计划

:::tip 前提
**每周投入约 10 小时，一年约 520 小时。**

**不要试图通读全部书籍。** 这份计划的目标是搭出**完整的知识链**，不是"读完这些书"。
:::

## 十二个月安排

| 时间 | 核心经典 | 阅读策略 |
|---|---|---|
| 第 1 月 | **Code** | 完整读 |
| 第 2–3 月 | **SICP** | 精读并完成部分习题，同时学习 Python |
| 第 4 月 | **CS:APP** | 核心章节 |
| 第 5 月 | **CLRS + OSTEP** | 精选算法与操作系统章节 |
| 第 6 月 | **Computer Networking + DDIA** | 网络基础精读，分布式系统选读 |
| 第 7 月 | **Deep Learning** | 重点读数学、神经网络和优化 |
| 第 8 月 | **Speech and Language Processing** | 精读语言模型与 Transformer |
| 第 9 月 | **AIMA** | Agent、搜索、规划与决策章节 |
| 第 10 月 | **Hands-On Large Language Models** | 核心实践章节 |
| 第 11 月 | **AI Engineering** | AI 工程核心章节 |
| 第 12 月 | **Agent 论文 + 综合项目** | 读论文并实现一个 Agent |

## 目前该怎么读

**这不是"一年掌握这些书"，是"一年读完核心章节"。**

| 类型 | 书 | 说明 |
|---|---|---|
| **完整读** | Code | 篇幅适中，逻辑连贯 |
| **精读 + 做题** | SICP、CS:APP、CLRS | 必须动手，光读没用 |
| **精选章节** | OSTEP、Networking、DDIA | 缺什么补什么 |
| **重点章节** | Deep Learning、SLP、AIMA | 关注与自己方向相关的部分 |

## 并行参考书

**Mathematics for Machine Learning** —— 全年并行。

**为什么**：数学薄弱会**直接限制**对深度学习、Transformer 的理解。不是"学不会"，而是"看不懂推导"，只能停在调包层面。

## 哪些书适合长期参考

这些**不建议排进第一年**，而是作为后续深入研究的长期参考：

| 书 | 什么时候用 |
|---|---|
| **PRML** | 想深入机器学习的概率基础时 |
| **Reinforcement Learning** | 想理解 Agent 决策理论时 |
| **An Introduction to MultiAgent Systems** | 深入多智能体理论时 |
| **TAOCP** | 做算法分析研究时 |
| **完整的 CLRS** | 终身参考 |
| **ESL** | 第一年之后，偏理论研究时 |

## 如果只选六本

**整个书单里最重要的六本**：

| 书 | 帮你掌握 |
|---|---|
| **SICP** | 程序抽象 |
| **CS:APP** | 计算机系统 |
| **CLRS** | 算法 |
| **Deep Learning** | 神经网络 |
| **Speech and Language Processing** | 语言模型 |
| **AIMA** | 智能体理论 |

**六本覆盖六条主干**——这是最少而完整的组合。
