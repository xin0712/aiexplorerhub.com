# 计算机经典书单

这份书单**不追新、不看热度、不管中英文**——只找真正经得起时间检验的经典。

## 筛选标准

| 维度 | 判断什么 |
|---|---|
| **学术地位** | 是否长期被世界知名大学采用或推荐 |
| **历史影响力** | 是否对计算机科学、软件工程或 AI 研究产生持续影响 |
| **原理深度** | 是否讲清底层机制，而不是只教某个框架的 API |
| **长期价值** | 十年之后，核心知识是否依然成立 |

参考来源：MIT、CMU、Stanford、UC Berkeley 的课程资料，以及 MIT Press、O'Reilly、Pearson 和原作者的官方资料。

## 一个重要的区分

**计算机科学有几十年沉淀的经典教材，但 LLM Agent 作为近年的工程方向，还没有同样成熟的公认经典书单。**

所以本清单把两者**分开**：

- **经典著作**——几十年验证过，十年后依然成立
- **当代前沿**——目前最有代表性，但地位尚未沉淀

## 按知识领域划分

不按「入门/进阶/高级」分，因为计算机不是一条难度阶梯，而是**多个并列的知识领域**——读者通常是「我想学算法」而不是「我想读进阶书」。

| 领域 | 包含 |
|---|---|
| [计算机原理与编程](./foundations) | Code、SICP、The C Programming Language、The Pragmatic Programmer |
| [算法与数据结构](./algorithms) | Introduction to Algorithms (CLRS)、TAOCP |
| [计算机系统](./systems) | CS:APP、OSTEP、Computer Networking、DDIA |
| [机器学习与深度学习](./ml-dl) | PRML、Deep Learning、Speech and Language Processing、Reinforcement Learning |
| [AI 与 Agent](./ai-agent) | AIMA、An Introduction to MultiAgent Systems |
| [大模型与前沿](./llm-frontier) | Hands-On LLMs、AI Engineering + 4 篇奠基论文 |
| [一年精读计划](./one-year-plan) | 怎么从这些书里排出可执行的顺序 |

## 如果只选六本

**SICP**（程序抽象）、**CS:APP**（计算机系统）、**CLRS**（算法）、**Deep Learning**（神经网络）、**Speech and Language Processing**（语言模型）、**AIMA**（智能体理论）。

这六本分别覆盖一条主干，足以构成完整知识链。

## 三条选书原则

> **经典书负责打底，原始论文负责理解思想来源，现代工程资料负责实现。**

三者缺一不可：只看经典会脱离当下，只看现代资料会不懂原理。
