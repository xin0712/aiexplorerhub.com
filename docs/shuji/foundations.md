# 计算机原理与编程

从这个领域开始最合适——**它回答「计算机到底是什么」和「程序到底是什么」**。

## Code: The Hidden Language of Computer Hardware and Software

**Charles Petzold** · 初版 1999 · 第 2 版 2022

**领域**：计算机工作原理

从信息编码、逻辑门、电路开始，一直讲到处理器和计算机系统。

**定位**：非常适合作为**整个学习计划的第一本书**。它不讲怎么编程，讲的是「这些0和1到底怎么变成一台能干活的机器」。

> 如果你从没想过「为什么计算机能算数」，这本书会给你答案。

## Structure and Interpretation of Computer Programs (SICP)

**Harold Abelson、Gerald Jay Sussman** · 1985 · 第 2 版 1996

**领域**：编程思想与计算抽象

MIT 极具影响力的编程教材。学习**抽象、递归、高阶函数、解释器和程序设计的本质**，而不仅是编程语法。

**定位**：理解「什么是程序」和「如何组织复杂计算」的核心著作。

> ⚠️ 这不是一本轻松的入门书。它的价值在于**改变你看程序的方式**，而不是教你某门语言。

## The C Programming Language

**Brian W. Kernighan、Dennis M. Ritchie** · 1978 · 第 2 版 1988

**领域**：编程语言基础

由 C 语言创造者之一 **Dennis Ritchie** 与 Brian Kernighan 合著，极具历史地位。学习变量、指针、内存、数据结构和系统接口。

**定位**：经典程度极高，但**对当前以 Python 构建 Agent 的路线属于选修**。

> 想理解「内存和指针」这类底层概念，它是最短的路。

## The Pragmatic Programmer

**Andrew Hunt、David Thomas** · 1999 · 20 周年版 2019

**领域**：软件工程

讲软件设计、代码维护、调试、自动化、重构，以及**优秀程序员的工作方法**。

**定位**：从「会编程」迈向「能够长期维护软件」的经典读物。

> 这本书教的不是技术，是**职业习惯**。

## 这几本怎么排

| 顺序 | 书 | 理由 |
|---|---|---|
| 1 | Code | 先知道机器怎么工作 |
| 2 | SICP | 再理解程序是什么 |
| 3 | The C Programming Language | 需要时补底层（选修） |
| 4 | The Pragmatic Programmer | 随时可读，常读常新 |

:::tip 提醒
**Code 可以完整读，SICP 要精读并做习题。** 两本都不是「一个月一本」的畅销书节奏。
:::
