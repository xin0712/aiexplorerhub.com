# 模型对比：质量 & 价格

:::warning 模型 ID 与价格会变
本页为 2026-10 快照。模型 ID 会随版本迭代更新，价格常变（尤其国内模型的峰谷价、订阅 vs 按量差异大）。**调用前务必以各厂商官方文档为准。**
:::

## 给 Agent 设计者的选型建议

- **文本**：默认用 deepseek-v4-flash / qwen-flash（便宜够用），要质量再上 deepseek-v4-pro / gpt-5.5 / claude-opus-5-5；
- **图片**：中文物料用 seedream / wan，要 API 集成用 flux（写实/可控）；
- **视频**：短剧角色一致用 kling / seedance，出海精品用 veo，批量预演用 vidu / MiniMax-H3。

## 模型去哪访问（云平台）

- **阿里系**（qwen、wan）→ 阿里云百炼 / PAI（人工智能平台）
- **字节系**（doubao、seedream、seedance）→ 火山方舟
- **DeepSeek** → DeepSeek 官方 API
- **智谱** → 智谱开放平台（bigmodel.cn）
- **月之暗面** → Kimi 开放平台
- **海外**（GPT / Claude / Gemini）→ 各官方 API / AWS Bedrock / Azure / Vertex AI
