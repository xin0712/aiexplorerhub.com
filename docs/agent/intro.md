# Agent 专栏导读

想搞懂 Agent？这一页说清楚整个专栏怎么学、四个部分各解决什么问题。

## 四个部分的分工（先记住这一句）

| 部分 | 回答什么 | 内容形态 |
|------|---------|---------|
| 基础篇 | 是什么 / 为什么 | 概念 + 图示 + 类比 |
| 进阶篇 | 怎么做 / 能不能跑通 | 代码 + 步骤 + 可复现结果 |
| 高级篇 | 怎么做好 / 怎么选 | 架构 + 对比 + 生产案例 |
| 资料篇 | 去哪查 / 有哪些 / 用哪个 | 清单 + 索引 + 选型指南 |

一句话：**基础篇讲概念，进阶篇讲动手，高级篇讲取舍，资料篇讲索引。**

## 建议学习路径

1. 通读「基础篇」，建立心智模型——先搞清楚 Agent 是什么、为什么、由哪些部分组成；
2. 跟着「进阶篇」的代码跑一遍——把概念变成能复现的结果；
3. 在真实项目里，用「高级篇」验证取舍——可靠、安全、成本、选型这些硬问题；
4. 把「资料篇」当工具书，随时查框架清单和术语。

## 关于「框架深挖」

进阶篇、高级篇会重点拆解 3 个开源框架，资料篇放全量清单。

建议顺序：先从资料篇的清单里挑一个框架，再回到进阶篇跟着对应的深挖章节动手——带着真实场景去读框架，比空看文档有用得多。
